# MESCHERYAKOV.DESIGNER — сайт-портфолио

Статический сайт без зависимостей: `index.html`, `styles.css`, `script.js`, папка `assets/`.
Открывается двойным кликом по `index.html` или с любого хостинга (GitHub Pages, Vercel, Tilda Zero-block → HTML, обычный FTP).

## Структура
- `index.html` — разметка четырёх экранов (Обо мне → Работы → Услуги → Контакты)
- `styles.css` — все стили. Размеры заданы в «дизайн-пикселях» макета 1440×900 через `calc(N * var(--px))`,
  поэтому сайт масштабируется пропорционально ширине окна. Ниже 760px — адаптивная мобильная версия.
- `script.js` — анимации и интерактив
- `assets/portrait.png` — фото (вырезано из макета; лучше заменить исходным PNG на прозрачном фоне, ~800×1400)
- `assets/web-*.jpg` — макеты сайтов (левая стопка), `assets/card-*.jpg` — карточки товара (правая колода)

## Что поменять под себя
- Цвет акцента: `--red` в `:root`
- Контакты: блок `.contacts__row` и ссылки в `.btn-red` / `.discuss`
- Ссылки на проекты: `figure.card` → оберните в `<a href="...">`
- Отключить прелоадер: удалите блок `#preloader` и вызов `runPreloader()` (вместо него `finishPreloader()`)

## Анимации
1. Прелоадер — побуквенное появление логотипа, счётчик 0–100 %, «шторка» уходит вверх
2. Полноэкранные секции: колесо/клавиши/свайп листают по одному экрану, индикатор справа анимируется
3. Заголовки появляются из маски построчно (translate + лёгкий поворот), тексты и кнопки — stagger-fade
4. Фото открывается clip-path снизу вверх с мягким zoom-out
5. Водяные знаки MESCHERYAKOV.DESIGNER — медленная бегущая строка + параллакс от курсора
6. Проекты. Левая стопка (сайты): задние карточки размыты; при наведении размытие снимается и карточка «прокручивается» на передний план, меняясь местами с передней; когда курсор покидает стопку, карточки плавно возвращаются в исходный порядок (спереди — X'FLOW GYM). Правая колода (карточки товара): при наведении карточка выскакивает вверх и становится чёткой. Подписи «Веб-сайты» / «карточки товара» появляются только при наведении. Плюс 3D-наклон, параллакс и «дыхание» передних карточек
7. Услуги: строки выезжают по очереди; при наведении номер краснеет, название сдвигается, красная линия прорисовывается, за курсором плывёт превью
8. Контакты: линия прорисовывается, ссылки подчёркиваются, кнопка — магнитная с заливкой; клик по e-mail/телефону копирует их в буфер
9. Кастомный курсор (точка + кольцо, режим «Смотреть» над проектами), магнитные кнопки
10. `prefers-reduced-motion` отключает анимации
